\section{Conclusion}
\label{sec:conclusion}

The aim was an assistant whose answers a reader can confirm without searching the datasheet. Code now checks every answer before it is shown: the quote must be on the cited page and every number must be in a quote. On 50 held-out questions, retrieval brought wrong answers from 4.3 per run to one in three runs, and that one came from a datasheet that states two values for the same quantity. The check alone withheld about a fifth of the correct answers; one revision with the reason for the rejection recovered 20 of 22, leaving the assistant 0.6 correct answers per run behind unchecked search, with every number it shows traceable to a quoted passage.

The check guarantees where a number came from, not that it answers the question. The open question is how often a verified answer quotes the wrong row, condition or column of a table. Answering it needs questions written by engineers who use these parts, checked against the PDF by a person, on datasheets the system has not seen, and a scorer that compares each answer with the table cell the question is about.
